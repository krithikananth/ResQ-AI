## 🎓 Git Commands Reference

### Daily Commands:
```powershell

git log --oneline --graph

git diff

git add .
git add specific-file.js

# Commit
git commit -m "message"

# Push
git push origin main

# Pull latest
git pull origin main
```

### Branch Management:
```powershell
# Create new branch
git checkout -b feature/new-feature

# Switch branches
git checkout main

# Merge branch
git merge feature/new-feature

# Delete branch
git branch -d feature/new-feature
```

### Undo Changes:
```powershell
# Discard changes in file
git restore file.js

# Undo last commit (keep changes)
git reset --soft HEAD~1

# Undo last commit (discard changes)
git reset --hard HEAD~1
```

## 📊 Commit Message Best Practices

### Format:
```
<type>: <short description>

<longer description (optional)>

<footer (optional)>
```

### Types:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `refactor`: Code refactoring
- `test`: Add tests
- `chore`: Maintenance

### Examples:
```
feat: add volunteer notification system

Implemented real-time notifications for volunteers when
new donations are available in their area.

Closes #45
```

```
fix: resolve volunteer dashboard filter issue

Updated query filter to include 'open' status donations
so volunteers can see all available pickups.
```

```
docs: update API documentation

Added examples for all donation endpoints and
authentication flow diagrams.
```

## 🐛 Troubleshooting

### Problem: "Your branch is behind"
**Solution:**
```powershell
git pull origin main
# Resolve any conflicts
git push origin main
```

### Problem: "Merge conflict"
**Solution:**
```powershell
# Open conflicted files
# Look for <<<<<, =====, >>>>> markers
# Edit to keep correct version
git add .
git commit -m "resolve merge conflict"
git push origin main
```

### Problem: "Large files rejected"
**Solution:**
```powershell
# Remove large files from git
git rm --cached path/to/large/file
echo "path/to/large/file" >> .gitignore
git commit -m "remove large file"
git push origin main
```

## 💡 Pro Tips

### Commit Often:
Make small, frequent commits rather than large ones:
```powershell
# Good: Small, focused commits
git commit -m "fix: update volunteer filter"
git commit -m "docs: add API examples"

# Not ideal: Large, unfocused commits
git commit -m "fixed everything and added docs"
```

### Use Branches:
For new features, use branches:
```powershell
git checkout -b feature/notifications
# Make changes
git commit -m "feat: add notification system"
git push origin feature/notifications
# Create pull request on GitHub
```

### Write Good Commit Messages:
- Start with verb: "add", "fix", "update", "remove"
- Be specific: "fix volunteer dashboard" not "fix bug"
- Reference issues: "Closes #123"
